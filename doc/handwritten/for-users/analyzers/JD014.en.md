# JD014: RejectedConstantArgument

🌍 **Languages:**  
🇬🇧 English (this file) | 🇫🇷 [Français](./JD014.fr.md)

| Property | Value |
|---|---|
| **Category** | Constraints (`JustDummies.Constraints`) |
| **Severity** | 🟠 Warning |
| **Enabled by default** | Yes |

The argument is a compile-time constant the generator's own guard refuses, so the call throws **every time it runs**. Nothing is decided at run time that is not already decided at the call site — yet the failure surfaces only when that arrange line executes, often inside a helper shared by many tests, where it reads as a library problem rather than as the transposition typo it usually is.

`Between(10, 5)` is the archetype: both parameters are `int`, both orders compile, and the mistake survives review because the call reads plausibly. It is checked on every numeric overload — `Any.Decimal().Between(100m, 1m)` and `Any.Int64().Between(10, 1)` throw exactly as the `int` one does — and so is `MultipleOf`, on every integer builder.

## Noncompliant

```csharp
Any.Int32().Between(10, 5)                    // the minimum must be ≤ the maximum — transposed
Any.String().WithLengthBetween(10, 5)         // same
Any.String().WithLength(-1)                   // a size must not be negative
Any.String().WithLength(2_000_000)            // above the largest producible size
Any.String().WithMaxLength(2_000_000)         // a ceiling steers the draw too, so it is capped as well
Any.Int32().MultipleOf(0)                     // the multiple must be strictly positive
Any.Decimal().WithScale(29)                   // the scale must be in [0, 28]
Any.String().StartingWith("")                 // the fragment must not be empty
Any.String().WithChars("")                    // the character pool must not be empty
Any.String().OneOf()                          // at least one value is required
Any.DateTime().WithGranularity(TimeSpan.Zero) // the granularity must be strictly positive

Any.DateTimeOffset().WithOffset(TimeSpan.FromSeconds(30))                            // an offset must be a whole number of minutes
Any.DateTimeOffset().WithOffset(TimeSpan.FromHours(15))                              // an offset must be within ±14:00
Any.DateTimeOffset().WithOffsetBetween(TimeSpan.FromHours(2), TimeSpan.FromHours(1)) // transposed
Any.Uri().Web().WithHost("münchen.de")                                               // a host must be ASCII: pass its punycode form
Any.Uri().Web().WithHost("10.1")                                                     // digits and dots must be a canonical dotted-quad
Any.Uri().Web().WithUserInfo("user", "p@ss")                                         // only unreserved characters: letters, digits, - . _ ~
Any.Uri().Mailto().WithLocalPart("first+last")                                       // same
Any.Double().OneOf(1.0, double.NaN)                                                  // NaN and the infinities are never generated
Any.Enum<Status>().OneOf((Status)99)                                                 // not a declared member
Any.Enum<Access>().OneOf((Access)8)                                                  // on [Flags], neither a member nor a combination of members
```

## Compliant

```csharp
Any.Int32().Between(5, 10)
Any.String().WithLength(12)
Any.Int32().MultipleOf(7)
Any.String().StartingWith("ORD-")
```

## Scope

One rule over one table, rather than a rule per method: the library validates these in one place, with one message shape, and a reader who learns "a constant the guard rejects" has learned all of them. The table mirrors `SizeGuard` and the per-generator guards exactly — where it cannot be certain, it stays silent.

Beyond a range or emptiness, the table replicates the guards that take more reading:

* a URI's **host** or a mailto **domain**: empty, not ASCII, or made of digits and dots without being a canonical dotted-quad such as `"1.2.3.4"`;
* a **user-info** part or a **local part**: any character but a letter, a digit, `-`, `.`, `_` or `~`;
* an **offset**: not a whole number of minutes, beyond ±14:00, or, for `WithOffsetBetween`, a minimum after its maximum;
* a **granularity** written in any spelling of a `TimeSpan` whose arguments are integral — `new TimeSpan(0)`, `TimeSpan.FromTicks(-1)` — not only `TimeSpan.Zero` and the `FromXxx` factories;
* a **`OneOf` value** on `Any.Double()` or `Any.Single()` that is not finite, and on `Any.Enum<T>()` one that is neither a declared member nor, on a `[Flags]` enumeration, a combination of declared members.

## What it does not flag

* A **non-constant** argument. That is the run-time guard's business, and it keeps it: this rule front-loads only the subset the compiler can already see.
* A conflict-asserting negative test — `Check.ThatCode(() => Any.Int32().Between(10, 5))` — where the illegal call is the whole body of a lambda argument. This repository writes hundreds of them.
* A same-named method on a type that is not a JustDummies generator.
* `Containing(item)` on a collection, which is not the string overload.
* A host the guard hands to `System.Uri` — anything but the three shapes above, such as `"::1"` or `"a b"`. Its parsing differs across target frameworks, so the rule cannot be certain the call throws wherever the test runs.
* A user-info part holding `İ` or the Kelvin sign, whose invariant lower case is an ASCII letter under some runtimes and globalization modes and not under others.
* A value given to the generic `Any.OneOf(...)`, which carries no finiteness or membership rule, by construction: `Any.OneOf(double.NaN, 1.0)` is legal. Nor an `Except(...)` value outside an enumeration's members, which removes nothing.
* A `null`, left to nullable analysis.
