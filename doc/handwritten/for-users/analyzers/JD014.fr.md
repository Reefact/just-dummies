# JD014 : RejectedConstantArgument

🌍 **Langues :**  
🇫🇷 Français (ce fichier) | 🇬🇧 [English](./JD014.en.md)

| Propriété | Valeur |
|---|---|
| **Catégorie** | Contraintes (`JustDummies.Constraints`) |
| **Sévérité** | 🟠 Avertissement |
| **Activée par défaut** | Oui |

L'argument est une constante de compilation que la garde du générateur refuse : l'appel lève **à chaque exécution**. Rien n'est décidé à l'exécution qui ne le soit déjà au site d'appel — pourtant l'échec ne se manifeste que lorsque cette ligne d'arrangement s'exécute, souvent au fond d'un utilitaire partagé par de nombreux tests, où il se lit comme un problème de bibliothèque plutôt que comme la faute de transposition qu'il est le plus souvent.

`Between(10, 5)` est l'archétype : les deux paramètres sont des `int`, les deux ordres compilent, et l'erreur survit à la relecture parce que l'appel se lit plausiblement. Il est vérifié sur chaque surcharge numérique — `Any.Decimal().Between(100m, 1m)` et `Any.Int64().Between(10, 1)` lèvent exactement comme celle en `int` — tout comme `MultipleOf`, sur chaque générateur entier.

## Non conforme

```csharp
Any.Int32().Between(10, 5)                    // le minimum doit être ≤ au maximum — transposés
Any.String().WithLengthBetween(10, 5)         // idem
Any.String().WithLength(-1)                   // une taille ne doit pas être négative
Any.String().WithLength(2_000_000)            // au-delà de la plus grande taille productible
Any.String().WithMaxLength(2_000_000)         // un plafond oriente le tirage aussi, donc il est plafonné également
Any.Int32().MultipleOf(0)                     // le multiple doit être strictement positif
Any.Decimal().WithScale(29)                   // l'échelle doit être dans [0, 28]
Any.String().StartingWith("")                 // le fragment ne doit pas être vide
Any.String().WithChars("")                    // le pool de caractères ne doit pas être vide
Any.String().OneOf()                          // au moins une valeur est requise
Any.DateTime().WithGranularity(TimeSpan.Zero) // la granularité doit être strictement positive

Any.DateTimeOffset().WithOffset(TimeSpan.FromSeconds(30))                            // un décalage doit être un nombre entier de minutes
Any.DateTimeOffset().WithOffset(TimeSpan.FromHours(15))                              // un décalage doit rester dans ±14:00
Any.DateTimeOffset().WithOffsetBetween(TimeSpan.FromHours(2), TimeSpan.FromHours(1)) // transposés
Any.Uri().Web().WithHost("münchen.de")                                               // un hôte doit être ASCII : utilisez sa forme Punycode
Any.Uri().Web().WithHost("10.1")                                                     // des chiffres et des points doivent former une adresse IPv4 canonique
Any.Uri().Web().WithUserInfo("user", "p@ss")                                         // seulement des caractères non réservés : lettres, chiffres, - . _ ~
Any.Uri().Mailto().WithLocalPart("first+last")                                       // idem
Any.Double().OneOf(1.0, double.NaN)                                                  // NaN et les infinis ne sont jamais générés
Any.Half().OneOf((Half)1, Half.NaN)                                                  // idem, sur Half
Any.Double().Between(double.NaN, 90.0)                                               // ni acceptés comme borne
```

## Conforme

```csharp
Any.Int32().Between(5, 10)
Any.String().WithLength(12)
Any.Int32().MultipleOf(7)
Any.String().StartingWith("ORD-")
```

## Portée

Une règle sur une table, plutôt qu'une règle par méthode : la bibliothèque valide tout cela au même endroit, avec une seule forme de message, et un lecteur qui a compris « une constante que la garde refuse » les a toutes comprises. La table reproduit exactement `SizeGuard` et les gardes propres à chaque générateur — là où elle ne peut pas être certaine, elle se tait.

Au-delà d'un intervalle ou d'une valeur vide, la table reproduit les gardes qui demandent plus de lecture :

* l'**hôte** d'une URI ou le **domaine** d'un mailto : vide, non ASCII, ou fait de chiffres et de points sans être une adresse IPv4 canonique comme `"1.2.3.4"` ;
* une partie d'**informations utilisateur** ou une **partie locale** : tout caractère autre qu'une lettre, un chiffre, `-`, `.`, `_` ou `~` ;
* un **décalage** : pas un nombre entier de minutes, au-delà de ±14:00, ou, pour `WithOffsetBetween`, un minimum postérieur à son maximum ;
* une **granularité** écrite dans n'importe quelle forme de `TimeSpan` à arguments entiers — `new TimeSpan(0)`, `TimeSpan.FromTicks(-1)` — et pas seulement `TimeSpan.Zero` et les fabriques `FromXxx` ;
* une **valeur de `OneOf`** non finie sur `Any.Double()`, `Any.Single()` ou `Any.Half()` ;
* une **borne** non finie sur ces trois générateurs — `Between`, `GreaterThan(OrEqualTo)`, `LessThan(OrEqualTo)`. `Half` n'a pas de constantes C# : son `NaN` et ses infinis sont lus comme les membres qu'ils sont, un `double` ou un `float` non fini reste lu à travers une conversion vers `Half`, et une constante finie trop grande pour un `Half` aussi : `(Half)70000.0` est un infini, puisque toute grandeur à partir de 65520 s'arrondit en un infini.

## Ce qui n'est pas signalé

* Un argument **non constant**. C'est l'affaire de la garde d'exécution, et elle la conserve : cette règle n'anticipe que le sous-ensemble déjà visible du compilateur.
* Un test négatif vérifiant un conflit — `Check.ThatCode(() => Any.Int32().Between(10, 5))` — où la chaîne qui porte l'appel illégal constitue tout le corps d'une lambda sans paramètre passée en argument. La chaîne peut se poursuivre au-delà de cet appel, comme dans `Assert.Throws<ArgumentException>(() => Any.Int32().Between(10, 5).Generate())` : [JD023](JD023.fr.md) se tait sur la même forme. Une chaîne passée à un autre appel à l'intérieur de la lambda reste signalée, tout comme une chaîne dans une lambda qui prend un paramètre, telle que `Select(_ => Any.Int32().Between(10, 5).Generate())` : cette lambda transforme une valeur, c'est du code d'arrange. Ce dépôt écrit des centaines de tests de ce genre.
* Une méthode homonyme portée par un type qui n'est pas un générateur JustDummies.
* `Containing(item)` sur une collection, qui n'est pas la surcharge chaîne.
* Un hôte que la garde confie à `System.Uri` — tout ce qui n'a pas l'une des trois formes ci-dessus, comme `"::1"` ou `"a b"`. Son analyse diffère d'un framework cible à l'autre : la règle ne peut pas être certaine que l'appel lève partout où le test s'exécute.
* Une partie d'informations utilisateur contenant `İ` ou le signe kelvin, dont la minuscule invariante est une lettre ASCII sous certains runtimes et modes de globalisation, et pas sous d'autres.
* Une valeur passée au `Any.OneOf(...)` générique, qui ne porte par construction aucune règle de finitude ni d'appartenance : `Any.OneOf(double.NaN, 1.0)` est légal. Pas davantage une valeur d'`Except(...)` hors des membres d'une énumération, qui ne retire rien.
* Une valeur de `OneOf` sur `Any.Enum<T>()` qui n'est ni un membre déclaré ni, sur une énumération `[Flags]`, une combinaison de membres déclarés. La garde la refuse, et [JD017](JD017.fr.md) la signale, avec un message qui nomme l'erreur de catégorie : une faute ne produit qu'un diagnostic.
* Un `Between` transposé sur deux valeurs `Half` finies écrites comme des conversions, comme `Between((Half)2.5, (Half)1)`. Deux nombres distincts peuvent s'arrondir au même `Half`, et la règle ne reproduit pas cet arrondi pour en décider.
* Un `null`, laissé à l'analyse de nullabilité.
