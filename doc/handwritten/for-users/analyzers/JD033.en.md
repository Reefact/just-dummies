# JD033: AnchoredLiteralOutsideCharacterFamily

🌍 **Languages:**  
🇬🇧 English (this file) | 🇫🇷 [Français](./JD033.fr.md)

| | |
|---|---|
| **Category** | Constraints (`JustDummies.Constraints`) |
| **Severity** | 🔵 Info |
| **Enabled by default** | Yes |

An anchored literal — a prefix, a suffix or a contained value — holds a character the declared character family, subtraction or casing cannot draw.

This is **legal, and it stays legal.** A character constraint governs the characters the generator *draws*, and a literal you wrote is not drawn, so it is kept exactly as written ([ADR-0077](../../for-maintainers/adr/0079-constrain-what-a-dummy-draws-never-the-literals-it-was-given.md)). That is precisely how a fixed separator is expressed:

<!-- jd:allow=JD033 -->
```csharp
string reference = Any.String().AlphaNumeric().StartingWith("ORD-").WithLengthBetween(8, 20).Generate();
// ORD-7K2P9QW — the hyphen is the separator, and the body stays alphanumeric
```

So the rule reports a **fact, not a fault**: that character appears where you wrote it and nowhere else. It is information because only you can tell the deliberate case from the one you did not mean.

## Reported

<!-- jd:allow=JD033 -->
```csharp
AnyString reference = Any.String().AlphaNumeric().StartingWith("ORD-").WithLength(12);    // cannot draw the '-'
AnyString batch     = Any.String().WithoutNumeric().StartingWith("ORD-1").WithLength(12); // removes the '1'
AnyString slug      = Any.String().UpperCase().StartingWith("ord-").WithLength(12);       // cannot draw the 'o'
```

The first two are almost certainly what their author meant. The third almost certainly is not — and it is the reason this rule exists, because the run time no longer refuses it.

## Not reported

<!-- jd:allow=JD029 -->
```csharp
AnyString digits = Any.String().Numeric().StartingWith("123").WithLength(12);    // the family draws every character
AnyString plain  = Any.String().StartingWith("ORD-").WithLength(12);             // no family: the draw is all of ASCII
AnyString cased  = Any.String().UpperCase().StartingWith("ORD-").WithLength(12); // a casing rules letters; '-' is not one
AnyString pooled = Any.String().AlphaNumeric().OneOf("ORD-1");                   // a value set: see below
```

* A **non-constant** literal, family or pool.
* A chain **split across statements or variables**. The chain must be written as one expression: following a generator through a local would need dataflow.
* A **conflict-asserting negative test**, where the chain is the whole body of a lambda argument.

## Why a value set is silent here

Once `OneOf(...)` is declared there is no filler: the caller supplies the whole value, so nothing is drawn beside the literal and "appears only where you wrote it" has no subject. A pooled value a constraint refuses is not kept-as-written at all — it is removed from the pool, which is a different fact, and [JD029](JD029.en.md) reports it as the removal it is.

## Turning it off

It is information, so it costs nothing to leave on. If a codebase writes fixed-prefix formats everywhere and the note stops carrying news:

```ini
dotnet_diagnostic.JD033.severity = none
```
