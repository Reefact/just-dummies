# JD033 : AnchoredLiteralOutsideCharacterFamily

🌍 **Langues :**  
🇫🇷 Français (ce fichier) | 🇬🇧 [English](./JD033.en.md)

| | |
|---|---|
| **Catégorie** | Contraintes (`JustDummies.Constraints`) |
| **Sévérité** | 🔵 Info |
| **Activée par défaut** | Oui |

Un littéral ancré — préfixe, suffixe ou valeur contenue — porte un caractère que la famille de caractères, la soustraction ou la casse déclarée ne peut pas tirer.

C'est **légal, et cela le reste.** Une contrainte de caractères gouverne les caractères que le générateur *tire*, et un littéral que vous avez écrit n'est pas tiré : il est donc conservé exactement tel quel ([ADR-0077](../../for-maintainers/adr/0079-constrain-what-a-dummy-draws-never-the-literals-it-was-given.fr.md)). C'est précisément ainsi qu'un séparateur fixe s'exprime :

<!-- jd:allow=JD033 -->
```csharp
string reference = Any.String().AlphaNumeric().StartingWith("ORD-").WithLengthBetween(8, 20).Generate();
// ORD-7K2P9QW — le tiret est le séparateur, et le corps reste alphanumérique
```

La règle rapporte donc un **fait, pas une faute** : ce caractère apparaît là où vous l'avez écrit et nulle part ailleurs. C'est une information parce que vous seul distinguez le cas délibéré de celui que vous ne vouliez pas.

## Signalé

<!-- jd:allow=JD033 -->
```csharp
AnyString reference = Any.String().AlphaNumeric().StartingWith("ORD-").WithLength(12);    // ne peut pas tirer le '-'
AnyString batch     = Any.String().WithoutNumeric().StartingWith("ORD-1").WithLength(12); // retire le '1'
AnyString slug      = Any.String().UpperCase().StartingWith("ord-").WithLength(12);       // ne peut pas tirer le 'o'
```

Les deux premiers sont presque certainement ce que leur auteur voulait. Le troisième presque certainement pas — et c'est la raison d'être de cette règle, puisque l'exécution ne le refuse plus.

## Non signalé

<!-- jd:allow=JD029 -->
```csharp
AnyString digits = Any.String().Numeric().StartingWith("123").WithLength(12);    // la famille tire chaque caractère
AnyString plain  = Any.String().StartingWith("ORD-").WithLength(12);             // aucune famille : le tirage couvre l'ASCII
AnyString cased  = Any.String().UpperCase().StartingWith("ORD-").WithLength(12); // une casse régit les lettres ; '-' n'en est pas
AnyString pooled = Any.String().AlphaNumeric().OneOf("ORD-1");                   // un ensemble de valeurs : voir ci-dessous
```

* Un littéral, une famille ou un pool **non constants**.
* Une chaîne **répartie sur plusieurs instructions ou variables**. Elle doit être écrite comme une seule expression : suivre un générateur à travers une variable locale exigerait une analyse de flot.
* Un **test négatif vérifiant un conflit**, où la chaîne constitue tout le corps d'une lambda passée en argument.

## Pourquoi un ensemble de valeurs est muet ici

Dès qu'un `OneOf(...)` est déclaré, il n'y a plus de remplissage : l'appelant fournit la valeur entière, donc rien n'est tiré à côté du littéral et « n'apparaît que là où vous l'avez écrit » n'a plus de sujet. Une valeur fournie qu'une contrainte refuse n'est pas conservée telle quelle du tout — elle est retirée du pool, ce qui est un autre fait, et [JD029](JD029.fr.md) le rapporte comme le retrait qu'il est.

## La désactiver

C'est une information : la laisser active ne coûte rien. Si une base de code écrit des formats à préfixe fixe partout et que la note cesse d'apprendre quoi que ce soit :

```ini
dotnet_diagnostic.JD033.severity = none
```
