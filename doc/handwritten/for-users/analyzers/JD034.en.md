# JD034: ConstraintAlreadyDefined

🌍 **Languages:**  
🇬🇧 English (this file) | 🇫🇷 [Français](./JD034.fr.md)

| Property | Value |
|---|---|
| **Category** | Constraints (`JustDummies.Constraints`) |
| **Severity** | 🟠 Warning |
| **Enabled by default** | Yes |

A chain declares a constraint the generator takes only once a second time, with a different call — or puts a casing beside a `WithChars` pool. The chain throws a `ConflictingAnyConstraintException` at that call, on every seed, saying the first declaration is already defined.

An `Any.String()` chain takes each of these once:

| constraint | calls |
|---|---|
| exact length | `WithLength` |
| prefix | `StartingWith` |
| suffix | `EndingWith` |
| character family or pool | `Alpha`, `Numeric`, `AlphaNumeric`, `Hexadecimal`, `Punctuation`, `Printable`, `NonPrintable`, `Whitespaces`, `WithChars` |
| casing | `InUpperCase`, `InLowerCase` |
| value set | `OneOf` |

A `WithChars` pool is the whole character definition, so it takes no casing either, whichever of the two comes first.

## Noncompliant

<!-- jd:allow=JD034 -->
```csharp
AnyString code      = Any.String().Alpha().AlphaNumeric().WithLength(8);              // one family, even one that agrees
AnyString reference = Any.String().StartingWith("ORD-").StartingWith("INV-").WithLength(12);
AnyString size      = Any.String().WithLength(8).Alpha().WithLength(10);
AnyString token     = Any.String().WithChars("abc123").InUpperCase().WithLength(8);   // a pool takes no casing
```

## Compliant

```csharp
AnyString code      = Any.String().AlphaNumeric().WithLength(8);
AnyString reference = Any.String().StartingWith("ORD-").WithLength(12);
AnyString size      = Any.String().Alpha().WithLength(10);
AnyString token     = Any.String().WithChars("ABC123").WithLength(8);                 // write the pool in the casing you want
```

Keep the declaration you meant and delete the other. If you meant several values, list them in one `OneOf(...)`; if you meant several characters, write them in one `WithChars(...)`.

## A conflict of declaration, not of values

The library refuses the second declaration whatever the values would make of it. `Alpha().AlphaNumeric()` is refused although every letter satisfies both: the generator has one place for its character family, and a second, different family is a contradiction in what the chain says, not in what it could draw.

That is what separates this rule from [JD015](JD015.en.md), which reports constants that admit no value — two lengths no string satisfies, a prefix longer than the declared length, a family its subtractions empty. Both rules report a chain that throws every time; each names a different reason, and a chain can carry both.

The diagnostic lands on the **second** declaration, where the exception is thrown, and names the first one as the library's message does. Only the first conflict in the chain is reported: nothing after it is ever applied.

## What it does not flag

* **The same call repeated.** `Alpha().Alpha()` or `WithLength(8).WithLength(8)` asks for nothing new, and the library ignores the repetition. A value set counts as the same when it lists the same values, in any order and with any repetition, so `OneOf("EUR", "USD").OneOf("USD", "EUR")` is silent too ([ADR-0100](../../for-maintainers/adr/0100-identify-a-value-set-by-its-values.md)).
* **An argument the compiler cannot resolve.** `StartingWith(prefix).StartingWith("ORD-")` is a repetition when `prefix` is `"ORD-"` and a conflict otherwise; the rule cannot tell which, so it stays silent rather than guess. Two different calls are still reported whatever their arguments: `Alpha().WithChars(pool)` never declares the same thing twice, and a casing refuses any pool.
* **A constraint that accumulates or folds.** Contained values, subtractions and exclusions accumulate, and a bound declared twice folds to the tighter one: that is [JD032](JD032.en.md)'s to report.
* **A chain split across statements or variables.** A generator held under a name is a recipe of its own; the rule reads one expression at a time.
* **A chain asserted to throw**, as the other constraint rules do.
* **Other generators, for now.** `Any.Char()`, the numeric and temporal generators, URIs and collections have constraints of their own that they take once, and the library refuses them the same way; this rule reads `Any.String()` chains only.
