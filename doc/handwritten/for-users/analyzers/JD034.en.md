# JD034: ConstraintAlreadyDefined

🌍 **Languages:**  
🇬🇧 English (this file) | 🇫🇷 [Français](./JD034.fr.md)

| Property | Value |
|---|---|
| **Category** | Constraints (`JustDummies.Constraints`) |
| **Severity** | 🟠 Warning |
| **Enabled by default** | Yes |

A chain redeclares a once-only constraint using a different call, or combines a `WithChars` pool with a casing constraint. The library rejects the second declaration immediately, regardless of the random seed, with a `ConflictingAnyConstraintException` saying the first one is already defined.

Each generator accepts only one declaration of each of these:

| generator | constraint | calls |
|---|---|---|
| `Any.String()` | exact length | `WithLength` |
| `Any.String()` | prefix | `StartingWith` |
| `Any.String()` | suffix | `EndingWith` |
| `Any.String()` | character family or pool | `Alpha`, `Numeric`, `AlphaNumeric`, `Hexadecimal`, `Punctuation`, `Printable`, `NonPrintable`, `Whitespaces`, `WithChars` |
| `Any.Char()` | character family | the same families, without `WithChars` |
| `Any.String()`, `Any.Char()` | casing | `InUpperCase`, `InLowerCase` |
| every generator that offers it | value set | `OneOf` |
| the integer generators | step | `MultipleOf`, `Odd`, `Even` |
| `Any.Decimal()` | scale | `WithScale` |
| `Any.DateTime()`, `Any.DateTimeOffset()`, `Any.TimeOnly()`, `Any.TimeSpan()` | granularity | `WithGranularity` |
| `Any.DateTimeOffset()` | offset | `WithOffset`, `WithOffsetBetween` |
| collections and dictionaries | exact count | `WithCount`, `Empty` |
| `Any.Uri().Web()` | scheme | `UsingHttp`, `UsingHttps` |
| `Any.Uri().WebSocket()` | scheme | `UsingWs`, `UsingWss` |
| `Web()`, `WebSocket()` and `Ftp()` URIs | host | `WithHost` |
| `Web()`, `WebSocket()` and `Ftp()` URIs | port | `WithPort` |
| `Web()` and `Ftp()` URIs | user info | `WithUserInfo` |
| `Web()`, `WebSocket()`, `Ftp()` and `Relative()` URIs | path | `WithPathSegments`, `WithoutPath` |
| `Any.Uri().Mailto()` | domain | `WithDomain` |
| `Any.Uri().Mailto()` | local part | `WithLocalPart` |

A `WithChars` pool completely defines the allowed characters of a string and cannot be combined with a casing constraint, whichever comes first.

## Noncompliant

<!-- jd:allow=JD034 -->
```csharp
AnyString         code      = Any.String().Alpha().AlphaNumeric().WithLength(8);              // two families, even though every letter satisfies both
AnyString         reference = Any.String().StartingWith("ORD-").StartingWith("INV-").WithLength(12);
AnyString         size      = Any.String().WithLength(8).Alpha().WithLength(10);
AnyString         token     = Any.String().WithChars("abc123").InUpperCase().WithLength(8);   // WithChars cannot be combined with a casing constraint
AnyInt32          quantity  = Any.Int32().Positive().MultipleOf(5).MultipleOf(10);            // one step per generator, even when one divides the other
AnyDateTimeOffset stamp     = Any.DateTimeOffset().WithOffset(TimeSpan.FromHours(1)).WithOffsetBetween(TimeSpan.FromHours(-5), TimeSpan.FromHours(1));
AnyList<int>      scores    = Any.ListOf(Any.Int32()).Empty().WithCount(0);                   // Empty() already declares the count
AnyWebUri         endpoint  = Any.Uri().Web().UsingHttps().WithPort(8080).WithPort(8443);
```

## Compliant

```csharp
AnyString         code      = Any.String().AlphaNumeric().WithLength(8);
AnyString         reference = Any.String().StartingWith("ORD-").WithLength(12);
AnyString         size      = Any.String().Alpha().WithLength(10);
AnyString         token     = Any.String().WithChars("ABC123").WithLength(8);                 // list the characters in the casing you want
AnyInt32          quantity  = Any.Int32().Positive().MultipleOf(10);
AnyDateTimeOffset stamp     = Any.DateTimeOffset().WithOffsetBetween(TimeSpan.FromHours(-5), TimeSpan.FromHours(1));
AnyList<int>      scores    = Any.ListOf(Any.Int32()).Empty();
AnyWebUri         endpoint  = Any.Uri().Web().UsingHttps().WithPort(8443);
```

Keep the declaration you meant and delete the other. If you meant several values, list them in a single `OneOf(...)`; if you meant several characters, list them in a single `WithChars(...)`; if you meant a range of offsets, declare it once with `WithOffsetBetween(...)`.

## A conflict of declaration, not of values

The library rejects the second declaration even if both constraints would allow the same values. `Alpha().AlphaNumeric()` is rejected although every letter satisfies both: the generator holds a single character family, so a second, different one contradicts what the chain declares, not what it could draw. The same goes for `MultipleOf(5).MultipleOf(10)`, although every multiple of ten is a multiple of five, and for `Empty().WithCount(0)`, which declares the same count with a different call.

That is what separates this rule from [JD015](JD015.en.md), which reports constants that admit no value — two lengths no string satisfies, a prefix longer than the declared length, a family its subtractions empty. Both rules report a chain that throws on every run; each gives a different reason, and a chain can trigger both.

The diagnostic is placed on the **second** declaration, where the exception is thrown, and names the first one, as the library's message does. Only the first conflict in a chain is reported, because nothing after it is ever applied.

## What it does not flag

* **The same call repeated.** `Alpha().Alpha()` or `WithLength(8).WithLength(8)` asks for nothing new: the library ignores the repetition, and [JD035](JD035.en.md) reports it. A value set counts as the same when it lists the same values, in any order and with any repetition, so `OneOf("EUR", "USD").OneOf("USD", "EUR")` is not reported either ([ADR-0100](../../for-maintainers/adr/0100-identify-a-value-set-by-its-values.md)); on a `double`, `OneOf(1)` and `OneOf(1.0)` list the same value. A granularity counts as the same when it has the same length, however its `TimeSpan` is written, and an offset when it declares the same range, so `WithOffset(TimeSpan.FromHours(1))` followed by `WithOffsetBetween(TimeSpan.FromHours(1), TimeSpan.FromHours(1))` is one declaration.
* **A call that narrows nothing.** `MultipleOf(1)` and a granularity of one tick allow every value, so the library ignores them and they leave room for the declaration that follows.
* **An argument the compiler cannot resolve.** `StartingWith(prefix).StartingWith("ORD-")` is a repetition when `prefix` is `"ORD-"` and a conflict otherwise; the rule cannot tell which, so it stays silent rather than guessing. The same goes for a value set held in a variable: a `OneOf` is read only when its values are written inline, as arguments or as a collection expression. A `TimeSpan` is read from `TimeSpan.Zero`, `TimeSpan.FromHours(2)` and its siblings, and `new TimeSpan(...)`, with whole-number arguments only: a fractional one is rounded differently from one .NET version to another, so the rule does not compute it. Two different methods are still reported whatever their arguments: `Alpha().WithChars(pool)` never declares the same thing twice, and a casing constraint can never be combined with a pool.
* **A call that rejects its own argument.** `WithCount(-1)`, `MultipleOf(0)`, an empty prefix, a port of `0`, a `null`, an offset that is not a whole number of minutes within ±14:00: each call checks its argument before it reads what the chain already declares, so it throws an argument exception rather than a conflict, and nothing after it is applied. [JD014](JD014.en.md) reports most of these. A host or a domain other than a plain DNS name is checked by `System.Uri` at run time, which the rule does not replicate, so the rule stays silent from that call on.
* **A second `Distinct` comparer.** A collection is distinct under one equality only, but the library compares comparers by reference, so no reading of the source can tell the same comparer from a different one.
* **A constraint that accumulates, or a repeated bound.** Contained values, subtractions and exclusions accumulate — written again identically, they are [JD035](JD035.en.md)'s — and a bound declared twice is narrowed to the tighter one, which [JD032](JD032.en.md) reports.
* **A chain split across statements or variables.** A generator held under a name is a recipe of its own; the rule reads one expression at a time.
* **The `DifferentFrom` an expression typed `IAny<T>` reaches.** It is the rejective exclusion, which redraws at generation time and declares nothing in a builder's specification; the rule reads only a typed builder's own `DifferentFrom`, the constructive one ([ADR-0121](../../for-maintainers/adr/0121-exclude-a-value-from-any-generator-by-redrawing.md)).
