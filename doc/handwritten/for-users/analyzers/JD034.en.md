# JD034: ConstraintAlreadyDefined

🌍 **Languages:**  
🇬🇧 English (this file) | 🇫🇷 [Français](./JD034.fr.md)

| Property | Value |
|---|---|
| **Category** | Constraints (`JustDummies.Constraints`) |
| **Severity** | 🟠 Warning |
| **Enabled by default** | Yes |

A chain redeclares a once-only constraint using a different call, or combines a `WithChars` pool with a casing constraint. The library rejects the second declaration immediately, regardless of the random seed, with a `ConflictingAnyConstraintException` saying the first one is already defined.

Each `Any.String()` generator accepts only one declaration of each of these:

| constraint | calls |
|---|---|
| exact length | `WithLength` |
| prefix | `StartingWith` |
| suffix | `EndingWith` |
| character family or pool | `Alpha`, `Numeric`, `AlphaNumeric`, `Hexadecimal`, `Punctuation`, `Printable`, `NonPrintable`, `Whitespaces`, `WithChars` |
| casing | `InUpperCase`, `InLowerCase` |
| value set | `OneOf` |

A `WithChars` pool completely defines the allowed characters and cannot be combined with a casing constraint, whichever comes first.

## Noncompliant

<!-- jd:allow=JD034 -->
```csharp
AnyString code      = Any.String().Alpha().AlphaNumeric().WithLength(8);              // two families, even though every letter satisfies both
AnyString reference = Any.String().StartingWith("ORD-").StartingWith("INV-").WithLength(12);
AnyString size      = Any.String().WithLength(8).Alpha().WithLength(10);
AnyString token     = Any.String().WithChars("abc123").InUpperCase().WithLength(8);   // WithChars cannot be combined with a casing constraint
```

## Compliant

```csharp
AnyString code      = Any.String().AlphaNumeric().WithLength(8);
AnyString reference = Any.String().StartingWith("ORD-").WithLength(12);
AnyString size      = Any.String().Alpha().WithLength(10);
AnyString token     = Any.String().WithChars("ABC123").WithLength(8);                 // list the characters in the casing you want
```

Keep the declaration you meant and delete the other. If you meant several values, list them in a single `OneOf(...)`; if you meant several characters, list them in a single `WithChars(...)`.

## A conflict of declaration, not of values

The library rejects the second declaration even if both constraints would allow the same values. `Alpha().AlphaNumeric()` is rejected although every letter satisfies both: the generator holds a single character family, so a second, different one contradicts what the chain declares, not what it could draw.

That is what separates this rule from [JD015](JD015.en.md), which reports constants that admit no value — two lengths no string satisfies, a prefix longer than the declared length, a family its subtractions empty. Both rules report a chain that throws on every run; each gives a different reason, and a chain can trigger both.

The diagnostic is placed on the **second** declaration, where the exception is thrown, and names the first one, as the library's message does. Only the first conflict in a chain is reported, because nothing after it is ever applied.

## What it does not flag

* **The same call repeated.** `Alpha().Alpha()` or `WithLength(8).WithLength(8)` asks for nothing new, and the library ignores the repetition. A value set counts as the same when it lists the same values, in any order and with any repetition, so `OneOf("EUR", "USD").OneOf("USD", "EUR")` is not reported either ([ADR-0100](../../for-maintainers/adr/0100-identify-a-value-set-by-its-values.md)).
* **An argument the compiler cannot resolve.** `StartingWith(prefix).StartingWith("ORD-")` is a repetition when `prefix` is `"ORD-"` and a conflict otherwise; the rule cannot tell which, so it stays silent rather than guessing. The same goes for a value set held in a variable: a `OneOf` is read only when its values are written inline, as arguments or as a collection expression. Two different methods are still reported whatever their arguments: `Alpha().WithChars(pool)` never declares the same thing twice, and a casing constraint can never be combined with a pool.
* **A constraint that accumulates, or a repeated bound.** Contained values, subtractions and exclusions accumulate, and a bound declared twice is narrowed to the tighter one, which [JD032](JD032.en.md) reports.
* **A chain split across statements or variables.** A generator held under a name is a recipe of its own; the rule reads one expression at a time.
* **A chain that a test asserts to throw**, which the other constraint rules ignore too.
* **Other generators, for now.** `Any.Char()`, the numeric and temporal generators, URIs and collections have once-only constraints of their own, which the library rejects the same way; for now, this rule reads only `Any.String()` chains.
