# JD034 : ConstraintAlreadyDefined

🌍 **Langues :**  
🇫🇷 Français (ce fichier) | 🇬🇧 [English](./JD034.en.md)

| Propriété | Valeur |
|---|---|
| **Catégorie** | Contraintes (`JustDummies.Constraints`) |
| **Sévérité** | 🟠 Avertissement |
| **Activée par défaut** | Oui |

Une chaîne déclare une seconde fois, avec un appel différent, une contrainte que le générateur ne prend qu'une fois — ou place une casse à côté d'un pool `WithChars`. La chaîne lève une `ConflictingAnyConstraintException` à cet appel, à chaque graine, en indiquant que la première déclaration est déjà définie.

Une chaîne `Any.String()` prend chacune de ces contraintes une seule fois :

| contrainte | appels |
|---|---|
| longueur exacte | `WithLength` |
| préfixe | `StartingWith` |
| suffixe | `EndingWith` |
| famille de caractères ou pool | `Alpha`, `Numeric`, `AlphaNumeric`, `Hexadecimal`, `Punctuation`, `Printable`, `NonPrintable`, `Whitespaces`, `WithChars` |
| casse | `InUpperCase`, `InLowerCase` |
| ensemble de valeurs | `OneOf` |

Un pool `WithChars` est la définition complète des caractères : il n'accepte donc pas non plus de casse, quel que soit l'ordre des deux.

## Non conforme

<!-- jd:allow=JD034 -->
```csharp
AnyString code      = Any.String().Alpha().AlphaNumeric().WithLength(8);              // une seule famille, même compatible
AnyString reference = Any.String().StartingWith("ORD-").StartingWith("INV-").WithLength(12);
AnyString size      = Any.String().WithLength(8).Alpha().WithLength(10);
AnyString token     = Any.String().WithChars("abc123").InUpperCase().WithLength(8);   // un pool n'accepte pas de casse
```

## Conforme

```csharp
AnyString code      = Any.String().AlphaNumeric().WithLength(8);
AnyString reference = Any.String().StartingWith("ORD-").WithLength(12);
AnyString size      = Any.String().Alpha().WithLength(10);
AnyString token     = Any.String().WithChars("ABC123").WithLength(8);                 // écrivez le pool dans la casse voulue
```

Gardez la déclaration que vous vouliez et supprimez l'autre. Si vous vouliez plusieurs valeurs, listez-les dans un seul `OneOf(...)` ; si vous vouliez plusieurs caractères, écrivez-les dans un seul `WithChars(...)`.

## Un conflit de déclaration, pas de valeurs

La bibliothèque refuse la seconde déclaration quoi qu'en feraient les valeurs. `Alpha().AlphaNumeric()` est refusé alors que toute lettre satisfait les deux : le générateur n'a qu'une place pour sa famille de caractères, et une seconde famille, différente, contredit ce que dit la chaîne, pas ce qu'elle pourrait tirer.

C'est ce qui distingue cette règle de [JD015](JD015.fr.md), qui signale des constantes n'admettant aucune valeur — deux longueurs qu'aucune chaîne ne satisfait, un préfixe plus long que la longueur déclarée, une famille que ses soustractions vident. Les deux règles signalent une chaîne qui lève une exception à chaque fois ; chacune en donne une raison différente, et une chaîne peut porter les deux.

Le diagnostic se place sur la **seconde** déclaration, là où l'exception est levée, et nomme la première comme le fait le message de la bibliothèque. Seul le premier conflit de la chaîne est signalé : rien de ce qui le suit n'est jamais appliqué.

## Ce qu'elle ne signale pas

* **Le même appel répété.** `Alpha().Alpha()` ou `WithLength(8).WithLength(8)` ne demande rien de nouveau, et la bibliothèque ignore la répétition. Un ensemble de valeurs compte comme le même quand il liste les mêmes valeurs, dans n'importe quel ordre et avec n'importe quelle répétition : `OneOf("EUR", "USD").OneOf("USD", "EUR")` n'est pas signalé non plus ([ADR-0100](../../for-maintainers/adr/0100-identify-a-value-set-by-its-values.fr.md)).
* **Un argument que le compilateur ne sait pas résoudre.** `StartingWith(prefix).StartingWith("ORD-")` est une répétition quand `prefix` vaut `"ORD-"`, et un conflit sinon ; la règle ne peut pas trancher, elle reste donc silencieuse plutôt que de deviner. Deux appels différents restent signalés quels que soient leurs arguments : `Alpha().WithChars(pool)` ne déclare jamais deux fois la même chose, et une casse refuse tout pool.
* **Une contrainte qui s'accumule ou se replie.** Les valeurs contenues, les soustractions et les exclusions s'accumulent, et une borne déclarée deux fois se replie sur la plus stricte : c'est à [JD032](JD032.fr.md) de la signaler.
* **Une chaîne répartie sur plusieurs instructions ou variables.** Un générateur conservé sous un nom est une recette à part entière ; la règle lit une expression à la fois.
* **Une chaîne dont on affirme qu'elle lève une exception**, comme pour les autres règles de contraintes.
* **Les autres générateurs, pour l'instant.** `Any.Char()`, les générateurs numériques et temporels, les URI et les collections ont leurs propres contraintes prises une seule fois, et la bibliothèque les refuse de la même manière ; cette règle ne lit que les chaînes `Any.String()`.
