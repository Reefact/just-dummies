# JD034 : ConstraintAlreadyDefined

🌍 **Langues :**  
🇫🇷 Français (ce fichier) | 🇬🇧 [English](./JD034.en.md)

| Propriété | Valeur |
|---|---|
| **Catégorie** | Contraintes (`JustDummies.Constraints`) |
| **Sévérité** | 🟠 Avertissement |
| **Activée par défaut** | Oui |

Une chaîne redéclare, avec un appel différent, une contrainte qui ne peut être déclarée qu'une seule fois, ou combine un pool `WithChars` avec `InUpperCase()` ou `InLowerCase()`. Quelle que soit la graine aléatoire, cette seconde déclaration provoque immédiatement une `ConflictingAnyConstraintException` indiquant que la première contrainte est déjà définie.

Chaque générateur `Any.String()` n'accepte qu'une seule déclaration de chacune de ces contraintes :

| contrainte | appels |
|---|---|
| longueur exacte | `WithLength` |
| préfixe | `StartingWith` |
| suffixe | `EndingWith` |
| famille de caractères ou pool | `Alpha`, `Numeric`, `AlphaNumeric`, `Hexadecimal`, `Punctuation`, `Printable`, `NonPrintable`, `Whitespaces`, `WithChars` |
| casse | `InUpperCase`, `InLowerCase` |
| ensemble de valeurs | `OneOf` |

Un pool `WithChars` définit entièrement les caractères autorisés : il ne peut donc pas être combiné avec une contrainte de casse, quel que soit l'ordre des deux.

## Non conforme

<!-- jd:allow=JD034 -->
```csharp
AnyString code      = Any.String().Alpha().AlphaNumeric().WithLength(8);              // deux familles, même si toute lettre satisfait les deux
AnyString reference = Any.String().StartingWith("ORD-").StartingWith("INV-").WithLength(12);
AnyString size      = Any.String().WithLength(8).Alpha().WithLength(10);
AnyString token     = Any.String().WithChars("abc123").InUpperCase().WithLength(8);   // WithChars ne peut pas être combiné avec une contrainte de casse
```

## Conforme

```csharp
AnyString code      = Any.String().AlphaNumeric().WithLength(8);
AnyString reference = Any.String().StartingWith("ORD-").WithLength(12);
AnyString size      = Any.String().Alpha().WithLength(10);
AnyString token     = Any.String().WithChars("ABC123").WithLength(8);                 // définissez directement les caractères avec la casse souhaitée
```

Gardez la déclaration que vous vouliez et supprimez l'autre. Si vous vouliez plusieurs valeurs, listez-les dans un seul `OneOf(...)` ; si vous vouliez plusieurs caractères, listez-les dans un seul `WithChars(...)`.

## Un conflit de déclaration, pas de valeurs

La bibliothèque rejette cette nouvelle déclaration même lorsque les deux contraintes autoriseraient les mêmes valeurs. `Alpha().AlphaNumeric()` est rejeté alors que toute lettre satisfait les deux : le générateur ne porte qu'une seule famille de caractères, si bien qu'une seconde famille, différente, contredit ce que déclare la chaîne, et non ce qu'elle pourrait tirer.

C'est ce qui distingue cette règle de [JD015](JD015.fr.md), qui signale des constantes n'admettant aucune valeur — deux longueurs qu'aucune chaîne ne satisfait, un préfixe plus long que la longueur déclarée, une famille que ses soustractions vident. Les deux règles signalent une chaîne qui provoque une exception à chaque exécution ; chacune en donne une raison différente, et une chaîne peut déclencher les deux.

Le diagnostic porte sur la **seconde** déclaration, là où l'exception se produit, et nomme la première, comme le fait le message de la bibliothèque. Seul le premier conflit d'une chaîne est signalé, car rien de ce qui le suit n'est jamais appliqué.

## Ce qu'elle ne signale pas

* **Le même appel répété.** `Alpha().Alpha()` ou `WithLength(8).WithLength(8)` ne demande rien de nouveau, et la bibliothèque ignore la répétition. Un ensemble de valeurs compte comme le même quand il liste les mêmes valeurs, dans n'importe quel ordre et avec n'importe quelle répétition : `OneOf("EUR", "USD").OneOf("USD", "EUR")` n'est pas signalé non plus ([ADR-0100](../../for-maintainers/adr/0100-identify-a-value-set-by-its-values.fr.md)).
* **Un argument que le compilateur ne sait pas résoudre.** `StartingWith(prefix).StartingWith("ORD-")` est une répétition quand `prefix` vaut `"ORD-"`, et un conflit sinon ; la règle ne peut pas trancher, elle reste donc silencieuse plutôt que de deviner. Il en va de même d'un ensemble de valeurs conservé dans une variable : un `OneOf` n'est lu que lorsque ses valeurs sont écrites sur place, en arguments ou dans une expression de collection. Deux méthodes différentes restent signalées quels que soient leurs arguments : `Alpha().WithChars(pool)` ne déclare jamais deux fois la même chose, et une contrainte de casse ne peut jamais être combinée avec un pool.
* **Une contrainte qui s'accumule, ou une borne répétée.** Les valeurs contenues, les soustractions et les exclusions s'accumulent, et une borne déclarée deux fois est ramenée à la plus stricte, ce que [JD032](JD032.fr.md) signale.
* **Une chaîne répartie sur plusieurs instructions ou variables.** Un générateur conservé sous un nom est une recette à part entière ; la règle lit une expression à la fois.
* **Une chaîne dont un test vérifie qu'elle provoque une exception**, que les autres règles de contraintes ignorent aussi.
* **Les autres générateurs, pour l'instant.** `Any.Char()`, les générateurs numériques et temporels, les URI et les collections ont leurs propres contraintes à déclaration unique, que la bibliothèque rejette de la même manière ; pour l'instant, cette règle ne lit que les chaînes `Any.String()`.
