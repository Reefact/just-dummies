# JD034 : ConstraintAlreadyDefined

🌍 **Langues :**  
🇫🇷 Français (ce fichier) | 🇬🇧 [English](./JD034.en.md)

| Propriété | Valeur |
|---|---|
| **Catégorie** | Contraintes (`JustDummies.Constraints`) |
| **Sévérité** | 🟠 Avertissement |
| **Activée par défaut** | Oui |

Une chaîne redéclare, avec un appel différent, une contrainte qui ne peut être déclarée qu'une seule fois, ou combine un pool `WithChars` avec `InUpperCase()` ou `InLowerCase()`. Quelle que soit la graine aléatoire, cette seconde déclaration provoque immédiatement une `ConflictingAnyConstraintException` indiquant que la première contrainte est déjà définie.

Chaque générateur n'accepte qu'une seule déclaration de chacune de ces contraintes :

| générateur | contrainte | appels |
|---|---|---|
| `Any.String()` | longueur exacte | `WithLength` |
| `Any.String()` | préfixe | `StartingWith` |
| `Any.String()` | suffixe | `EndingWith` |
| `Any.String()` | famille de caractères ou pool | `Alpha`, `Numeric`, `AlphaNumeric`, `Hexadecimal`, `Punctuation`, `Printable`, `NonPrintable`, `Whitespaces`, `WithChars` |
| `Any.Char()` | famille de caractères | les mêmes familles, sans `WithChars` |
| `Any.String()`, `Any.Char()` | casse | `InUpperCase`, `InLowerCase` |
| tout générateur qui le propose | ensemble de valeurs | `OneOf` |
| les générateurs d'entiers | multiple | `MultipleOf` |
| `Any.Decimal()` | échelle | `WithScale` |
| `Any.DateTime()`, `Any.DateTimeOffset()`, `Any.TimeOnly()`, `Any.TimeSpan()` | granularité | `WithGranularity` |
| `Any.DateTimeOffset()` | décalage horaire | `WithOffset`, `WithOffsetBetween` |
| collections et dictionnaires | nombre exact d'éléments | `WithCount`, `Empty` |
| `Any.Uri().Web()` | schéma | `UsingHttp`, `UsingHttps` |
| `Any.Uri().WebSocket()` | schéma | `UsingWs`, `UsingWss` |
| URI `Web()`, `WebSocket()` et `Ftp()` | hôte | `WithHost` |
| URI `Web()`, `WebSocket()` et `Ftp()` | port | `WithPort` |
| URI `Web()` et `Ftp()` | informations utilisateur | `WithUserInfo` |
| URI `Web()`, `WebSocket()`, `Ftp()` et `Relative()` | chemin | `WithPathSegments`, `WithoutPath` |
| `Any.Uri().Mailto()` | domaine | `WithDomain` |
| `Any.Uri().Mailto()` | partie locale | `WithLocalPart` |

Un pool `WithChars` définit entièrement les caractères autorisés d'une chaîne : il ne peut donc pas être combiné avec une contrainte de casse, quel que soit l'ordre des deux.

## Non conforme

<!-- jd:allow=JD034 -->
```csharp
AnyString         code      = Any.String().Alpha().AlphaNumeric().WithLength(8);              // deux familles, même si toute lettre satisfait les deux
AnyString         reference = Any.String().StartingWith("ORD-").StartingWith("INV-").WithLength(12);
AnyString         size      = Any.String().WithLength(8).Alpha().WithLength(10);
AnyString         token     = Any.String().WithChars("abc123").InUpperCase().WithLength(8);   // WithChars ne peut pas être combiné avec une contrainte de casse
AnyInt32          quantity  = Any.Int32().Positive().MultipleOf(5).MultipleOf(10);            // un seul pas par générateur, même quand l'un divise l'autre
AnyDateTimeOffset stamp     = Any.DateTimeOffset().WithOffset(TimeSpan.FromHours(1)).WithOffsetBetween(TimeSpan.FromHours(-5), TimeSpan.FromHours(1));
AnyList<int>      scores    = Any.ListOf(Any.Int32()).Empty().WithCount(0);                   // Empty() déclare déjà le nombre d'éléments
AnyWebUri         endpoint  = Any.Uri().Web().UsingHttps().WithPort(8080).WithPort(8443);
```

## Conforme

```csharp
AnyString         code      = Any.String().AlphaNumeric().WithLength(8);
AnyString         reference = Any.String().StartingWith("ORD-").WithLength(12);
AnyString         size      = Any.String().Alpha().WithLength(10);
AnyString         token     = Any.String().WithChars("ABC123").WithLength(8);                 // définissez directement les caractères avec la casse souhaitée
AnyInt32          quantity  = Any.Int32().Positive().MultipleOf(10);
AnyDateTimeOffset stamp     = Any.DateTimeOffset().WithOffsetBetween(TimeSpan.FromHours(-5), TimeSpan.FromHours(1));
AnyList<int>      scores    = Any.ListOf(Any.Int32()).Empty();
AnyWebUri         endpoint  = Any.Uri().Web().UsingHttps().WithPort(8443);
```

Gardez la déclaration que vous vouliez et supprimez l'autre. Si vous vouliez plusieurs valeurs, listez-les dans un seul `OneOf(...)` ; si vous vouliez plusieurs caractères, listez-les dans un seul `WithChars(...)` ; si vous vouliez une plage de décalages, déclarez-la une seule fois avec `WithOffsetBetween(...)`.

## Un conflit de déclaration, pas de valeurs

La bibliothèque rejette cette nouvelle déclaration même lorsque les deux contraintes autoriseraient les mêmes valeurs. `Alpha().AlphaNumeric()` est rejeté alors que toute lettre satisfait les deux : le générateur ne porte qu'une seule famille de caractères, si bien qu'une seconde famille, différente, contredit ce que déclare la chaîne, et non ce qu'elle pourrait tirer. Il en va de même pour `MultipleOf(5).MultipleOf(10)`, bien que tout multiple de dix soit un multiple de cinq, et pour `Empty().WithCount(0)`, qui déclare le même nombre d'éléments par un autre appel.

C'est ce qui distingue cette règle de [JD015](JD015.fr.md), qui signale des constantes n'admettant aucune valeur — deux longueurs qu'aucune chaîne ne satisfait, un préfixe plus long que la longueur déclarée, une famille que ses soustractions vident. Les deux règles signalent une chaîne qui provoque une exception à chaque exécution ; chacune en donne une raison différente, et une chaîne peut déclencher les deux.

Le diagnostic porte sur la **seconde** déclaration, là où l'exception se produit, et nomme la première, comme le fait le message de la bibliothèque. Seul le premier conflit d'une chaîne est signalé, car rien de ce qui le suit n'est jamais appliqué.

## Ce qu'elle ne signale pas

* **Le même appel répété.** `Alpha().Alpha()` ou `WithLength(8).WithLength(8)` ne demande rien de nouveau : la bibliothèque ignore la répétition, et [JD035](JD035.fr.md) la signale. Un ensemble de valeurs compte comme le même quand il liste les mêmes valeurs, dans n'importe quel ordre et avec n'importe quelle répétition : `OneOf("EUR", "USD").OneOf("USD", "EUR")` n'est pas signalé non plus ([ADR-0100](../../for-maintainers/adr/0100-identify-a-value-set-by-its-values.fr.md)) ; sur un `double`, `OneOf(1)` et `OneOf(1.0)` listent la même valeur. Une granularité compte comme la même quand elle a la même durée, quelle que soit l'écriture de son `TimeSpan`, et un décalage quand il déclare la même plage : `WithOffset(TimeSpan.FromHours(1))` suivi de `WithOffsetBetween(TimeSpan.FromHours(1), TimeSpan.FromHours(1))` ne forme qu'une seule déclaration.
* **Un appel qui ne restreint rien.** `MultipleOf(1)` et une granularité d'un tick autorisent toutes les valeurs : la bibliothèque les ignore, et ils laissent la place à la déclaration qui suit.
* **Un argument que le compilateur ne sait pas résoudre.** `StartingWith(prefix).StartingWith("ORD-")` est une répétition quand `prefix` vaut `"ORD-"`, et un conflit sinon ; la règle ne peut pas trancher, elle reste donc silencieuse plutôt que de deviner. Il en va de même d'un ensemble de valeurs conservé dans une variable : un `OneOf` n'est lu que lorsque ses valeurs sont écrites sur place, en arguments ou dans une expression de collection. Un `TimeSpan` n'est lu que depuis `TimeSpan.Zero`, `TimeSpan.FromHours(2)` et ses semblables, ou `new TimeSpan(...)`, et seulement avec des arguments entiers : une valeur fractionnaire n'est pas arrondie de la même façon d'une version de .NET à l'autre, et la règle ne la calcule donc pas. Deux méthodes différentes restent signalées quels que soient leurs arguments : `Alpha().WithChars(pool)` ne déclare jamais deux fois la même chose, et une contrainte de casse ne peut jamais être combinée avec un pool.
* **Un appel qui rejette son propre argument.** `WithCount(-1)`, `MultipleOf(0)`, un préfixe vide, un port à `0`, un `null`, un décalage qui n'est pas un nombre entier de minutes compris entre −14:00 et +14:00 : chaque appel vérifie son argument avant de lire ce que la chaîne a déjà déclaré. Il provoque donc une exception sur l'argument plutôt qu'un conflit, et rien de ce qui le suit n'est appliqué. [JD014](JD014.fr.md) signale la plupart de ces cas. Un hôte ou un domaine autre qu'un simple nom DNS est vérifié par `System.Uri` à l'exécution, ce que la règle ne reproduit pas : elle reste donc silencieuse à partir de cet appel.
* **Un second comparateur `Distinct`.** Une collection n'est distincte que selon une seule égalité, mais la bibliothèque compare les comparateurs par référence : aucune lecture du code source ne permet de distinguer le même comparateur d'un autre.
* **Une contrainte qui s'accumule, ou une borne répétée.** Les valeurs contenues, les soustractions et les exclusions s'accumulent — écrites de nouveau à l'identique, elles relèvent de [JD035](JD035.fr.md) —, et une borne déclarée deux fois est ramenée à la plus stricte, ce que [JD032](JD032.fr.md) signale.
* **Une chaîne répartie sur plusieurs instructions ou variables.** Un générateur conservé sous un nom est une recette à part entière ; la règle lit une expression à la fois.
* **Le `DifferentFrom` qu'atteint une expression typée `IAny<T>`.** C'est l'exclusion rejective, qui retire au moment de la génération et ne déclare rien dans la spécification d'un builder ; la règle ne lit que le `DifferentFrom` propre à un builder typé, l'exclusion constructive ([ADR-0121](../../for-maintainers/adr/0121-exclude-a-value-from-any-generator-by-redrawing.fr.md)).
