# JD035: ConstraintRepeated

🌍 **Languages:**  
🇬🇧 English (this file) | 🇫🇷 [Français](./JD035.fr.md)

| Property | Value |
|---|---|
| **Category** | Constraints (`JustDummies.Constraints`) |
| **Severity** | 🟠 Warning |
| **Enabled by default** | Yes |

A chain declares a constraint again, exactly as it already declared it. The library ignores the second call: it keeps the declaration it already holds, or removes again what is already gone. Nothing throws and no draw changes, yet the line reads as though it were written for a reason, and nobody dares delete it.

The rule reads two kinds of constraint, and a value listed twice in one exclusion list, such as `Except("a", "a")`, which is the same exclusion declared twice in a single call:

| kind | calls |
|---|---|
| a constraint the generator takes once | every call [JD034](JD034.en.md) reads: character families and `WithChars`, `WithLength`, `StartingWith`, `EndingWith`, the casing constraints, `OneOf`, `MultipleOf`, `Odd` and `Even` (where `Even()` and `MultipleOf(2)` are one declaration), `WithScale`, `WithGranularity`, `WithOffset` and `WithOffsetBetween`, `WithCount` and a collection's `Empty`, and a URI's scheme, host, port, user info, path, domain and local part |
| a constraint whose repetition changes nothing | the exclusions `Except`, `DifferentFrom` and `NonZero`; the subtractions `WithoutAlpha` and `WithoutNumeric`; a string's `Containing`; `NotBlank`; `AllowingCombinations`; `Distinct()`; `True` and `False`; a `Guid`'s `Empty` and `NonEmpty`; and a URI's `WithQuery`, `WithFragment`, `WithHeaders` and `Rooted` |

## Noncompliant

<!-- jd:allow=JD035 -->
```csharp
AnyString    code     = Any.String().Alpha().WithLength(8).Alpha();             // Alpha() is already declared
AnyString    currency = Any.String().OneOf("EUR", "USD").OneOf("USD", "EUR");   // the same values, in another order
AnyInt32     quantity = Any.Int32().Positive().Except(13).Except(13);
AnyList<int> scores   = Any.ListOf(Any.Int32()).WithCount(3).Distinct().WithCount(3);
```

## Compliant

```csharp
AnyString    code     = Any.String().Alpha().WithLength(8);
AnyString    currency = Any.String().OneOf("EUR", "USD");
AnyInt32     quantity = Any.Int32().Positive().Except(13);
AnyList<int> scores   = Any.ListOf(Any.Int32()).WithCount(3).Distinct();
```

Delete the repeated call. If it was meant to say something else, write that instead: a different declaration of a constraint the generator takes once is refused ([JD034](JD034.en.md)), while an exclusion of another value is legal.

## Warning rather than Info

A dummy's declaration states what the value must satisfy, and nothing else. A call that states nothing new is noise a reader has to get past, and a reader who assumes it matters leaves it alone. [JD024](JD024.en.md) is information because an inert exclusion can document an intent that a future widening of the range makes real. A repetition documents nothing the first call did not: it is a copy-paste or a merge, the reading [ADR-0078](../../for-maintainers/adr/0078-own-a-bound-declared-twice-as-one-rule.md) gave a bound written twice when it put [JD032](JD032.en.md) at warning.

## What counts as the same

* the same method with the same constant arguments;
* a value set or an exclusion list with the same values, in any order and with any repetition ([ADR-0100](../../for-maintainers/adr/0100-identify-a-value-set-by-its-values.md)), each read as a value of the generator's own type, so on a `double`, `OneOf(1)` and `OneOf(1.0)` are the same;
* a granularity of the same length, however its `TimeSpan` is written: `TimeSpan.FromMinutes(60)` and `TimeSpan.FromHours(1)`;
* an offset declaring the same range: `WithOffset(x)` followed by `WithOffsetBetween(x, x)`;
* named arguments in any order.

The diagnostic is placed on the repeated call, the one to delete, and names the earlier one; for a value listed twice in one exclusion list, on the repeated value. Every repetition in a chain is reported, since the calls after one are still applied.

## What it does not flag

* **A different declaration.** `Alpha().Numeric()` is refused by the library, and [JD034](JD034.en.md) reports it.
* **A value listed twice in a value set.** `OneOf("a", "a")` reads as a weighting the library declines, and [JD025](JD025.en.md) reports it; so does a character written twice in a `WithChars` pool.
* **A bound declared again, or an alias of one.** `WithMinLength(4).WithMinLength(4)` folds rather than repeats, and [JD032](JD032.en.md) reports it; on an integer generator, `Positive().Positive()` and `Between(1, 9).Between(1, 9)` are [JD024](JD024.en.md)'s. A bound reached through an alias elsewhere — `NonEmpty()` on a string or a collection, `Positive()` on a `double` — stays silent, as it does for JD032.
* **An equivalent call that is not the same call.** `Except(5).DifferentFrom(5)`, `NonZero().Except(0)` and `Except("a", "b").Except("a")` remove nothing new, but none repeats the call before it; on an integer generator, [JD024](JD024.en.md) reports them.
* **A collection's contained element.** `Containing(1).Containing(1)` on a list requires the element twice, so the list holds two of them; a set or a dictionary refuses the second.
* **A call that narrows nothing.** `MultipleOf(1)` and a granularity of one tick allow every value, so there is nothing to repeat.
* **An argument the compiler cannot resolve.** `StartingWith(prefix).StartingWith(prefix)` may hold two different prefixes; the rule stays silent rather than guess. The same goes for a value set held in a variable, a `Guid` or a `DateTime` (never a constant), and a fractional `TimeSpan`.
* **A second `Distinct` comparer.** The library compares comparers by reference, so no reading of the source can tell the same comparer from a different one.
* **Anything after a call the library refuses** — a different declaration, or an argument a call rejects, which [JD014](JD014.en.md) reports — since nothing after it is applied.
* **A chain split across statements or variables.** A generator held under a name is a recipe of its own; the rule reads one expression at a time.
