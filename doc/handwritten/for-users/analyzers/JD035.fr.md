# JD035 : ConstraintRepeated

🌍 **Langues :**  
🇫🇷 Français (ce fichier) | 🇬🇧 [English](./JD035.en.md)

| Propriété | Valeur |
|---|---|
| **Catégorie** | Contraintes (`JustDummies.Constraints`) |
| **Sévérité** | 🟠 Avertissement |
| **Activée par défaut** | Oui |

Une chaîne déclare de nouveau une contrainte, exactement comme elle l'a déjà déclarée. La bibliothèque ignore ce second appel : elle conserve la déclaration qu'elle détient déjà, ou retire de nouveau ce qui a déjà disparu. Rien ne provoque d'exception et aucun tirage ne change ; pourtant, la ligne donne l'impression d'avoir été écrite pour une raison, et personne n'ose la supprimer.

La règle lit deux sortes de contraintes :

| sorte | appels |
|---|---|
| une contrainte que le générateur n'accepte qu'une fois | tous les appels que lit [JD034](JD034.fr.md) : les familles de caractères et `WithChars`, `WithLength`, `StartingWith`, `EndingWith`, les contraintes de casse, `OneOf`, `MultipleOf`, `WithScale`, `WithGranularity`, `WithOffset` et `WithOffsetBetween`, `WithCount` et le `Empty` d'une collection, ainsi que le schéma, l'hôte, le port, les informations utilisateur, le chemin, le domaine et la partie locale d'une URI |
| une contrainte dont la répétition ne change rien | les exclusions `Except`, `DifferentFrom` et `NonZero` ; les soustractions `WithoutAlpha` et `WithoutNumeric` ; le `Containing` d'une chaîne ; `NotBlank` ; `AllowingCombinations` ; `Distinct()` ; `True` et `False` ; les `Empty` et `NonEmpty` d'un `Guid` ; et les `WithQuery`, `WithFragment`, `WithHeaders` et `Rooted` d'une URI |

## Non conforme

<!-- jd:allow=JD035 -->
```csharp
AnyString    code     = Any.String().Alpha().WithLength(8).Alpha();             // Alpha() est déjà déclaré
AnyString    currency = Any.String().OneOf("EUR", "USD").OneOf("USD", "EUR");   // les mêmes valeurs, dans un autre ordre
AnyInt32     quantity = Any.Int32().Positive().Except(13).Except(13);
AnyList<int> scores   = Any.ListOf(Any.Int32()).WithCount(3).Distinct().WithCount(3);
```

## Conforme

```csharp
AnyString    code     = Any.String().Alpha().WithLength(8);
AnyString    currency = Any.String().OneOf("EUR", "USD");
AnyInt32     quantity = Any.Int32().Positive().Except(13);
AnyList<int> scores   = Any.ListOf(Any.Int32()).WithCount(3).Distinct();
```

Supprimez l'appel répété. S'il devait dire autre chose, écrivez plutôt cela : une autre déclaration d'une contrainte que le générateur n'accepte qu'une fois est refusée ([JD034](JD034.fr.md)), alors que l'exclusion d'une autre valeur est légale.

## Avertissement plutôt qu'information

La déclaration d'un dummy énonce ce que la valeur doit satisfaire, et rien d'autre. Un appel qui n'énonce rien de nouveau est un bruit que le lecteur doit franchir, et un lecteur qui le croit utile le laisse en place. [JD024](JD024.fr.md) relève de l'information parce qu'une exclusion inerte peut documenter une intention qu'un futur élargissement de l'intervalle rendra réelle. Une répétition ne documente rien que le premier appel ne disait déjà : c'est un copier-coller ou une fusion, la lecture que l'[ADR-0078](../../for-maintainers/adr/0078-own-a-bound-declared-twice-as-one-rule.fr.md) a donnée à une borne écrite deux fois en plaçant [JD032](JD032.fr.md) en avertissement.

## Ce qui compte comme la même déclaration

* la même méthode avec les mêmes arguments constants ;
* un ensemble de valeurs ou une liste d'exclusions aux mêmes valeurs, dans n'importe quel ordre et avec n'importe quelle répétition ([ADR-0100](../../for-maintainers/adr/0100-identify-a-value-set-by-its-values.fr.md)), chacune lue comme une valeur du type du générateur : sur un `double`, `OneOf(1)` et `OneOf(1.0)` sont donc identiques ;
* une granularité de même durée, quelle que soit l'écriture de son `TimeSpan` : `TimeSpan.FromMinutes(60)` et `TimeSpan.FromHours(1)` ;
* un décalage qui déclare la même plage : `WithOffset(x)` suivi de `WithOffsetBetween(x, x)` ;
* des arguments nommés dans n'importe quel ordre.

Le diagnostic porte sur l'appel répété, celui à supprimer, et nomme le précédent. Toutes les répétitions d'une chaîne sont signalées, car les appels qui suivent l'une d'elles restent appliqués.

## Ce qu'elle ne signale pas

* **Une déclaration différente.** `Alpha().Numeric()` est refusé par la bibliothèque, et [JD034](JD034.fr.md) le signale.
* **Une borne déclarée de nouveau, ou l'un de ses alias.** `WithMinLength(4).WithMinLength(4)` se replie au lieu de se répéter, et [JD032](JD032.fr.md) le signale ; sur un générateur d'entiers, `Positive().Positive()` et `Between(1, 9).Between(1, 9)` relèvent de [JD024](JD024.fr.md). Ailleurs, une borne atteinte par un alias — `NonEmpty()` sur une chaîne ou une collection, `Positive()` sur un `double` — reste muette, comme pour JD032.
* **Un appel équivalent qui n'est pas le même appel.** `Except(5).DifferentFrom(5)`, `NonZero().Except(0)` et `Except("a", "b").Except("a")` ne retirent rien de nouveau, mais aucun ne répète l'appel qui le précède ; sur un générateur d'entiers, [JD024](JD024.fr.md) les signale.
* **L'élément contenu d'une collection.** `Containing(1).Containing(1)` sur une liste exige l'élément deux fois : la liste en contient donc deux ; un ensemble ou un dictionnaire refuse le second.
* **Un appel qui ne restreint rien.** `MultipleOf(1)` et une granularité d'un tick autorisent toutes les valeurs : il n'y a rien à répéter.
* **Un argument que le compilateur ne sait pas résoudre.** `StartingWith(prefix).StartingWith(prefix)` peut contenir deux préfixes différents ; la règle reste silencieuse plutôt que de deviner. Il en va de même d'un ensemble de valeurs conservé dans une variable, d'un `Guid` ou d'un `DateTime` (jamais constants), et d'un `TimeSpan` fractionnaire.
* **Un second comparateur `Distinct`.** La bibliothèque compare les comparateurs par référence : aucune lecture du code source ne permet de distinguer le même comparateur d'un autre.
* **Tout ce qui suit un appel que la bibliothèque refuse** — une déclaration différente, ou un argument qu'un appel rejette, que [JD014](JD014.fr.md) signale —, puisque rien de ce qui le suit n'est appliqué.
* **Une chaîne répartie sur plusieurs instructions ou variables.** Un générateur conservé sous un nom est une recette à part entière ; la règle lit une expression à la fois.
* **Une chaîne dont un test vérifie qu'elle provoque une exception**, que les autres règles de contraintes ignorent aussi.
