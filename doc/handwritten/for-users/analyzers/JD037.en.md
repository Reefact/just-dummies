# JD037: DrawInsideCompositionLambda

🌍 **Languages:**  
🇬🇧 English (this file) | 🇫🇷 [Français](./JD037.fr.md)

| Property | Value |
|---|---|
| **Category** | Reproducibility (`JustDummies.Reproducibility`) |
| **Severity** | 🟠 Warning |
| **Enabled by default** | Yes |

A `Generate()` sits inside a lambda passed to `As(...)` or `Any.Combine(...)`. The lambda runs on every generation, so the inner value is drawn each time — but apart from the recipe it sits in, from whatever source the inner generator carries. Under an explicit `Any.WithSeed(...)` context, an inner generator built from the static `Any` draws from the ambient seed instead: the run then replays only partly from the seed it reports.

## Noncompliant

<!-- jd:allow=JD037 -->
```csharp
AnyContext any = Any.WithSeed(20261101);

IAny<(int Capacity, int Cells)> sampleGenerator = any.Int32().Between(10, 500)
    .As(capacity => (capacity, Any.Int32().Between(1, capacity - 1).Generate()));   // JD037
```

## Compliant

When the second value is an offset from the first, compose the offset — it holds by construction, and the chain is one recipe:

```csharp
AnyContext any = Any.WithSeed(20261101);

IAny<(int Start, int End)> spanGenerator = Any.Combine(
    any.Int32().Between(0, 1_000),
    any.Int32().Between(1, 30),
    (start, length) => (start, start + length));
```

When the second generator depends on the first value in a way an offset cannot express, derive it with `Then`, which draws it on the same source:

```csharp
AnyContext any = Any.WithSeed(20261101);

IAny<(int Capacity, int Cells)> sampleGenerator = any.Int32().Between(10, 500)
    .Then(capacity => Any.Int32().Between(1, capacity - 1).As(cells => (capacity, cells)));
```

Both replay from the one seed the context reports ([ADR-0119](../../for-maintainers/adr/0119-draw-a-value-that-depends-on-another-draw.md)). The offset — its unit, its bounds — is yours to choose, which is why the rule offers no code fix.

## What it does not flag

* A `Generate()` outside a composition lambda, at the call site or in a `Func` you call yourself.
* A lambda passed to `Then`: it returns a generator, it does not draw one.
* An `As` or a `Combine` that is not JustDummies' own.

The rule reads where the draw sits, not where it draws from: a draw from the same explicit context inside the lambda replays, yet it is reported too, because it still mixes the recipe with the draw the library keeps apart, and the same two forms read better ([ADR-0120](../../for-maintainers/adr/0120-report-a-draw-made-inside-a-composition-lambda.md)).
