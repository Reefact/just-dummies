# JD037: DrawInsideCompositionLambda

🌍 **Langues :**  
🇬🇧 [English](./JD037.en.md) | 🇫🇷 Français (ce fichier)

| Propriété | Valeur |
|---|---|
| **Catégorie** | Reproducibility (`JustDummies.Reproducibility`) |
| **Sévérité** | 🟠 Avertissement |
| **Activée par défaut** | Oui |

Un `Generate()` se trouve dans une lambda passée à `As(...)` ou à `Any.Combine(...)`. La lambda s'exécute à chaque génération, donc la valeur intérieure est tirée à chaque fois — mais à l'écart de la recette où elle se trouve, depuis la source que porte le générateur intérieur, quelle qu'elle soit. Sous un contexte `Any.WithSeed(...)` explicite, un générateur intérieur construit à partir de l'`Any` statique tire alors de la graine ambiante : l'exécution ne se rejoue plus qu'en partie depuis la graine qu'elle annonce.

## Non conforme

<!-- jd:allow=JD037 -->
```csharp
AnyContext any = Any.WithSeed(20261101);

IAny<(int Capacity, int Cells)> sampleGenerator = any.Int32().Between(10, 500)
    .As(capacity => (capacity, Any.Int32().Between(1, capacity - 1).Generate()));   // JD037
```

## Conforme

Quand la seconde valeur est un décalage par rapport à la première, composez le décalage — il tient par construction, et la chaîne est une seule recette :

```csharp
AnyContext any = Any.WithSeed(20261101);

IAny<(int Start, int End)> spanGenerator = Any.Combine(
    any.Int32().Between(0, 1_000),
    any.Int32().Between(1, 30),
    (start, length) => (start, start + length));
```

Quand le second générateur dépend de la première valeur d'une façon qu'un décalage ne sait pas exprimer, dérivez-le avec `Then`, qui le tire sur la même source :

```csharp
AnyContext any = Any.WithSeed(20261101);

IAny<(int Capacity, int Cells)> sampleGenerator = any.Int32().Between(10, 500)
    .Then(capacity => Any.Int32().Between(1, capacity - 1).As(cells => (capacity, cells)));
```

Les deux se rejouent depuis la seule graine qu'annonce le contexte ([ADR-0119](../../for-maintainers/adr/0119-draw-a-value-that-depends-on-another-draw.fr.md)). Le décalage — son unité, ses bornes — est le vôtre à choisir, c'est pourquoi la règle ne propose aucun correctif automatique.

## Ce qu'elle ne signale pas

* Un `Generate()` hors d'une lambda de composition, au site d'appel ou dans un `Func` que vous appelez vous-même.
* Une lambda passée à `Then` : elle renvoie un générateur, elle n'en tire pas un.
* Un `As` ou un `Combine` qui n'est pas celui de JustDummies.

La règle lit où se trouve le tirage, pas d'où il tire : un tirage depuis le même contexte explicite dans la lambda se rejoue, mais il est signalé lui aussi, parce qu'il mêle encore la recette au tirage que la bibliothèque garde séparés, et que les deux mêmes formes se lisent mieux ([ADR-0120](../../for-maintainers/adr/0120-report-a-draw-made-inside-a-composition-lambda.fr.md)).
