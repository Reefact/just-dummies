# JD038 : ScalarChainAdmitsOneValue

🌍 **Langues :**  
🇬🇧 [English](./JD038.en.md) | 🇫🇷 Français (ce fichier)

| Propriété | Valeur |
|---|---|
| **Catégorie** | Contraintes (`JustDummies.Constraints`) |
| **Sévérité** | 🟠 Avertissement |
| **Activée par défaut** | Oui |

Les contraintes constantes réduisent le domaine à **exactement une valeur** : la chaîne tire une constante déguisée en tirage. Ce qui est significatif reste un littéral : une valeur que le test a choisie s'écrit comme telle, et un tirage qui ne peut pas varier est le littéral choisi à la main que cette bibliothèque existe pour remplacer ([ADR-0129](../../for-maintainers/adr/0129-report-a-chain-whose-constants-admit-exactly-one-value.fr.md)).

La règle réutilise le repliement de [JD023](JD023.fr.md) — le même parcours sur les mêmes types exacts, qui demande combien il reste plutôt que s'il reste quelque chose — et se tait pour tout argument qu'elle ne peut pas replier.

## Non conforme

<!-- jd:allow=JD038,JD031 -->
```csharp
int     anyQuantity = Any.Int32().Between(5, 5).Generate();                                  // JD038 : toujours 5
int     anyRetries  = Any.Int32().GreaterThanOrEqualTo(3).LessThanOrEqualTo(3).Generate();   // un plancher et un plafond qui se rejoignent
int     anyPort     = Any.Int32().OneOf(8080).Generate();                                    // un ensemble d'une seule valeur
int     anyWeek     = Any.Int32().Between(1, 10).MultipleOf(7).Generate();                   // un seul point reste sur le treillis
decimal anyRate     = Any.Decimal().Between(1m, 1.4m).WithScale(0).Generate();              // 1 est la seule valeur sur la grille
```

## Conforme

```csharp
int       quantity      = 5;                                         // la valeur que le test a choisie, écrite comme telle
IAny<int> portGenerator = Any.Fixed(8080);                           // un littéral là où un générateur est requis
int       anyRetries    = Any.Int32().Between(1, 5).Generate();      // une plage, quand le test ne s'en soucie pas
int       anyZero       = Any.Int32().Zero().Generate();             // un épinglage par son nom se lit comme la constante qu'il est
```

## Le message

Le diagnostic nomme la valeur unique et les deux issues :

```text
Any.Int32().Between(5, 5)
JD038: Write the literal 5, or Any.Fixed(5) where a generator is required: the constraints declared on this chain admit exactly one value
```

Sur une heure de la journée, il nomme aussi `Any.TimeOnly()` : `Between(t, t)` reste la seule valeur `t` sur tous les types ([ADR-0125](../../for-maintainers/adr/0125-let-a-time-of-day-window-cross-midnight.fr.md)), et un test qui l'a écrit pour toute la journée apprend ce qui nomme la journée.

Le diagnostic est placé sur l'appel après lequel une seule valeur reste, là où vous pouvez agir.

## Dans la fabrique d'un générateur

Les deux issues changent le type : le littéral est un `int`, `Any.Fixed(1)` un `IAny<int>`. Là où le code
doit produire le builder lui-même — le lambda de raffinement d'un générateur scaffoldé, un
`Func<AnyInt32, AnyInt32>`, ou un champ ou une fabrique typés `AnyInt32` — aucune ne compile. Alors :

* dans un lambda de raffinement, la valeur unique est un épinglage, pas un raffinement : appelez plutôt la
  surcharge d'épinglage du générateur, `WithCapacity(1)` plutôt que `WithCapacity(c => c.Between(1, 1))` ;
* dans un générateur que vous écrivez, typez le champ ou la fabrique `IAny<int>` là où ils peuvent porter
  une constante, et affectez `Any.Fixed(1)` ;
* là où le type du builder ne peut pas changer, gardez la chaîne et faites taire la règle sur ce membre avec
  un `[SuppressMessage]` nommant `JustDummiesRule.JD038`, dont la justification dit pourquoi le builder est
  requis.

## Portée

Les types exacts que lit [JD023](JD023.fr.md), avec le même repliement : les générateurs entiers, `Decimal` et les générateurs temporels. Un ensemble de valeurs réduit à une seule, une plage dont les deux bornes se rejoignent, un plancher et un plafond qui ne laissent qu'une valeur entre eux, un treillis dont un seul point reste dans la plage, une exclusion qui n'en laisse qu'une.

## Pourquoi un avertissement

Un diagnostic de niveau information n'atteint jamais un terminal ni un journal de CI : une règle à cette sévérité n'enseigne rien là où une compilation se lit ([JD030](JD030.fr.md) dit comment en relever une). Et il n'existe pas de lecture défensive d'une plage constante réduite à un point : une équipe qui écrit `Between(5, 5)` pour documenter que la valeur compte a écrit la raison du littéral, pas le littéral, et le littéral est plus clair.

## Ce qui n'est pas signalé

* Une valeur épinglée **par son nom** — `Zero()` — qui se lit déjà comme la constante qu'elle est, quelle que soit la suite de la chaîne.
* Une chaîne qui n'admet aucune valeur, qui relève de [JD023](JD023.fr.md), et une chaîne qu'une autre règle possède d'abord : un second ensemble de valeurs ou un second treillis ([JD034](JD034.fr.md)), une plage transposée ou un pas refusé ([JD014](JD014.fr.md)).
* Une chaîne dont un argument ne se replie pas en constante : une borne calculée depuis un autre tirage n'est jamais signalée.
* Un générateur flottant binaire (`Double`, `Single`, `Half`), et une borne `UInt64` égale ou supérieure à `long.MaxValue`, que [JD023](JD023.fr.md) laisse aussi sans jugement.
* Une plage plus large que les quelques dizaines de valeurs que la règle parcourt : un domaine réduit à une valeur en excluant une large plage valeur par valeur n'est pas compté, et pas signalé.
* Une chaîne répartie sur plusieurs instructions — elle doit être une seule expression.

Pas de correctif de code : remplacer le générateur par le littéral change le type du site d'appel, et sur une heure de la journée l'intention est ambiguë.
