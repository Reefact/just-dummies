## Frictions and surprises, in order
1. `dotnet test --project Tests.Discovery` -> `MSBUILD : error MSB1001: Unknown switch. ... Switch: --project`. On .NET 10 the `--project` form only exists in Microsoft.Testing.Platform mode; nothing in the docs (getting-started, xunit page) says that a global.json `{ "test": { "runner": "Microsoft.Testing.Platform" } }` is needed with `xunit.v3`. I put that global.json in my domain folder. Not strictly a library problem but the xunit page lists "Install" without the runner step.
2. The docs I was given link to `doc/handwritten/for-users/...` and `../../for-maintainers/adr/...`, which do not exist next to my copy of the docs (`docs/guides/...`). As a consumer I could not follow ~every ADR reference, and the guides lean on them to explain surprising rules. Minor.
3. First `any generate` before restore: "this project has not been restored, so its package references cannot be read. Restore it, then run the command again: dotnet restore". Clear and actionable; I restored and it worked. (Good message; just noting that the getting-started path does not mention restoring first.)
4. `Surface(double)`: guard `Math.Round(squareMeters, 2) != squareMeters` is left `to verify`, and the recipe it proposes (`Any.Double().Positive().LessThanOrEqualTo(Max)`) draws values with arbitrary decimals, so (I did not run it, the sentinel stops the build first) it would fail the constructor on essentially every draw. The numbers page says `double` has no `WithScale`, but nothing suggests the idiom for a "double on a hundredth grid"; I found it by combining `Any.Int32().Between` + `.As(h => h / 100d)`. It worked first time (no rounding mismatch over 300+ draws). A doc line "a double on a decimal grid: draw an integer and divide" next to the numbers page would have saved a detour. Also this forces the retyping of field/ctor/`Func` (3 edits) which is documented for `AnyPattern` but I had to infer it for `IAny<double>`.
5. `EnergyPerformanceDiagnosis`: `ThrowIfNegative` guards and ordinary constants are read; the rating-vs-figures guard marks 4 parameters at once ("unread guard ... line 22") and the scaffold would draw a random `EnergyRating` independent of the figures: it would fail on most draws (not run: the sentinel stops the build first). Expected by the docs ("every other rule between parameters ... to verify, the build stops"), and the compile-time stop worked as advertised. The doc's "derive one draw from another inside Generate()" form fits, but I had to give up the `With...` for the derived parameter and write my own `OfRating`; the docs mention the consequence (pins no longer reach the draw) which I was glad to have read.
6. `Transfer`: `ArgumentOutOfRangeException.ThrowIfLessThan(registeredOn, signedOn)` (an order between two parameters) is reported as an unread guard, while `if (availableFrom >= availableUntil)` in `RentalListing` is turned into `Any.OrderedPair`. The CLI page says `ThrowIfNegative` "and its siblings" are read; the two-parameter `ThrowIfLessThan/ThrowIfGreaterThan` helpers are a natural form of `a < b` and I expected them to be paired. I copied the tool's own pin-aware OrderedPair block from `AnyRentalListing` into `AnyTransfer` by hand.
7. `RentalListing`: `property.CanBeLetOn(availableFrom)` ties a property and a date through a method of the other object. The tool flagged both with "ties property to availableFrom" (nice), but the recipe it kept for the property draws any rating, so I had to design "draw an A-D property, then a start in its validity" myself. It took the longest of all generators. The docs' `Then`/`OrderedPair` pages gave me the pieces; nothing shows an example mixing a domain object's property (`property.Diagnosis.ValidUntil`) with `Any.OrderedPair` bounds in `Generate()`.
8. `.WithDiagnosis(Any.EnergyPerformanceDiagnosis().OfRating(G))` -> `CS1503: Argument 1: cannot convert from 'AnyEnergyPerformanceDiagnosis' to 'EnergyPerformanceDiagnosis'` (8 errors). The docs do say a `With...` takes a value or a lambda, never a generator, and "prepared generator is reused as a lambda", so I fixed it with `diagnosis => diagnosis.OfRating(G)`. The error is exactly the documented one, but nothing in the message hints at the lambda form; I learned it from the page. Once understood it reads well.
9. `AnyProperty` documents: the scaffolded `Any.ListOf(new AnyDocumentLink()).WithMaxCount(20)` would not honour "locations pairwise distinct" and `Distinct()` on `DocumentLink` compares references. The `to verify` mark saved me. Writing the real generator needed `ListOf(uri).Distinct().Then(...)`, a second `ListOf(...).WithCount(locations.Count)` and a `Zip` in `As`. It works (300 draws, and a test checks the invariant), but it is the most convoluted spot of the project and there is no doc example of "a list of objects distinct by one of their members".
10. Entry point: `--entry-point any` produced `Any.Surface()`, `Any.Property()` ... via C# 14 `extension(Any)`; the project compiled without any language-version change on the .NET 10 SDK. It worked.
11. No analyzer diagnostic appeared at any time. I wrote `Any.Int32().Between(1, (int)(Surface.MaxSquareMeters * 100))` and many `Any.DateOnly()` generators with no hint; fine, but I cannot say whether JD030/JD036 stay silent because Info is hidden (the CLI page says Info never prints in `dotnet build`).
12. `Any.DateTime()` is documented as always Kind=Utc; I relied on it for `DocumentLink.uploadedAtUtc` and it held (no failures in 300+ draws per run, 13 runs).
13. Domain findings the tests revealed (all literal inputs, so deterministic): a trailing `\n` is accepted in a cadastral reference (`$` anchor) and lets a `0000` plan number bypass the `EndsWith("0000")` rule; `\d` accepts non-ASCII digits (`٧٥٠٥٦ 000 AB 0123`); `Property` constructor throws `NullReferenceException` for a null document in the list; `Surface.Add(null)` throws `NullReferenceException` instead of `ArgumentNullException`. Not library issues.

## What worked well
- The "dummy vs literal" discipline from core-concepts translated directly: in every test I could name which values were the subject (literal) and which were not (drawn). `Any.Transfer().WithSignedOn(d).WithRegisteredOn(d.AddDays(30))` or `Any.Property().WithKind(PropertyKind.Commercial).WithDiagnosis(d => d.OfRating(G))` read as the test's intent with price/parcel/documents left arbitrary.
- The scaffolder's refusals are real help: the build stops at the exact line with the guard quoted, and 5 of the 7 types had something I really had to look at (regex, helper validation, cross-parameter rule, distinct locations, a tie between objects). It never gave me a plausible-but-wrong generator silently. Its recap table (`guard`, `AnyX`, `to verify`) was readable and its `Positive()`/`LessThanOrEqualTo(Surface.MaxSquareMeters)`/`Between` guard reading was right every time it spoke.
- Composition between scaffolded generators (`new AnySurface()` inside `AnyProperty`, `OrderedPair` for dates) worked on the first build once the `TODO`s were resolved.
- `[assembly: Reproducible]` plus the seed shown in the output of a failing test (e.g. `[JustDummies] These arbitrary values were seeded with 168142443. Reproduce this run with [JustDummies.Xunit.Reproducible(Seed = 168142443)].`) is exactly the replay story promised; the 5 expected failures printed it.
- Clear separation of "pin a value" vs "refine": `WithKind(kind => kind.Except(PropertyKind.Commercial))` for "a home, whichever kind" was natural.
- 12 repeated runs with fresh seeds stayed green (237/0/5), including 300-draw generator checks.
